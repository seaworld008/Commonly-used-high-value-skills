# v3.2.0 — Grill Me 与全量技能维护

本版本在 v3.1.0 基础上新增 `grill-me`，累计更新 74 个原有技能的内容或资源，保留全部公开技能入口：**287 个技能、16 个分类**。新增技能由 PR #127 独立交付，维护与审查修复集中在 PR #129；不会把临时传输分支合入 main。

## 主要变化

- **Grill Me 完整收录**：固定 Matt Pocock v1.2.3 的提交与 MIT 许可，保留 `grill-me` / `grilling` 上游原文，并提供中文独立方法、决策树模板和安装回归。单独安装不依赖缺失的 `/grilling`，不会因安装或审计而自动开始访谈。
- **按差异策展而非盲目覆盖**：更新 23 个飞书技能及配套资源、安全审计、GitHub Actions 审查、Neon/Lakebase、Graphify 等；保留本地授权、跨客户端适配和中文展示。发布前另审阅 43 个新候选：8 个吸收更新、31 个源文件未变、4 个保留本地实现，拒绝新增的强制停顿规则和无关营销文字。
- **修复真实行为问题**：安装器安全归档悬空目标链接并在失败时恢复；图表检查只默认读取明确可见的网格表，显式非网格目标会拒绝，超时/无效 JSON 的只读调用最多重试一次，权限错误及写命令不重试。修复 `throw;` 和无效 Prisma 回滚示例，Xquik 示例禁用凭证请求重定向，性能优化长示例改为随技能打包的按需参考。
- **治理失效跟踪**：107 个上游已移除的旧辅助路径保留为带不可变提交和许可的历史参考，不继续伪装成实时镜像，不删除仍在使用的公开技能路径。25 个策略冻结条目保留原政策，不声称其为最新上游版本。

[首轮完整审计](../maintenance-audit-2026-09-30.md) / [首轮逐项 JSON](../maintenance-audit-2026-09-30.json) 是历史记录，不改写当时统计和哈希。[发布前补充审阅](../maintenance-followup-2026-10-03.md) / [补充逐项 JSON](../maintenance-followup-2026-10-03.json) 记录新比较提交、许可证据、采用/保留理由和最终修改哈希。观测 `2026-10-03T19:20:12Z` 的 153 个跟踪条目中，85 个无需新改动、43 个随后完成策展、0 个不可用、25 个按策略冻结；移动分支仍可能在观测后变化。

## 发布制品

GitHub Release 提供源码归档、npm 格式安装包、`release-manifest.json` 与 `SHA256SUMS`。发布流程从通过检查的 main SHA 构建，上传为草稿后重新下载，逐项验证 SHA-256、包版本、所需文件、Git 内容和执行位，成功后才公开并设为 Latest。npm 按标准打包规则省略的 ignore 控制文件在制品清单中明确列出，不能遗漏运行资源。

这不是 npm registry 发布，不会修改任何用户的全局技能安装或模型配置。静态、离线、安装器及制品检查不等同于真实模型行为评测、live SaaS/数据库或生产环境验收。质量启发式审阅提示不被当作能力评分，也不通过删除可用技能来消除提示。
