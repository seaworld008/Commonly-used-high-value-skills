# v7.0.0 · 组合演进、精选新技能与全仓质量升级

本主要版本（Major Release）在 `v6.2.0` 基础上完成全仓组合去重优化、通用模板清理、质量标准与触发边界打磨、浏览器基础能力升级与 5 项高价值技能精选入库；结合 PR #161/#162/#163 合并的 `modern-web-guidance` 与上游发现加固，全仓规范技能规模现为 **295 个技能 / 16 个分类**，组合审计平均分达到 **95.0**（`295/295 keep`，`review` 队列清零）。

## 精选新增技能

本版本周期累计新增（含 `v6.2.0` 后并入的 `modern-web-guidance` 与本次精选的 5 项高价值技能）：

- **`claude-api`**（`ai-agent-platform`，Apache-2.0，评分 100）：Anthropic 多语言官方 SDK、Tool Runner、Prompt Caching、Refusal Fallbacks 与 Managed Agents 完整工程指南；14 节速查表拆分至 `references/api-quick-reference.md`。
- **`accessibility-engineering`**（`ai-workflow`，MIT，评分 100）：WCAG 2.2 AA 无障碍工程审计与人工键盘/读屏核查流程，附带 `references/accessibility-checklist.md` 与 `scripts/audit-a11y.sh`（`0755`）。
- **`cloudflare-agents-sdk`**（`deployment-platforms`，Apache-2.0，评分 100）：Cloudflare Agents SDK（Durable Objects SQLite、`@callable` RPC、AgentWorkflow、MCP、流式会话），与 `cloudflare-deploy` / `cloudflare-troubleshooting` 明确边界。
- **`review-animations`**（`product-design`，MIT，评分 95）：基于 Emil Kowalski 工程美学的 UI 动效审查标准与 `STANDARDS.md`，移除单一宿主停顿与屏蔽标志。
- **`ab-test-design`**（`product-design`，MIT，评分 92）：A/B 实验设计、护栏与防闪烁特性开关实施规范，附带 `scripts/sample_size.py` 样本量与周期计算器。
- **`modern-web-guidance`**（`developer-engineering`，已在 PR #161/#162 并入）：Google Modern Web Guidance 架构与质量指引。
