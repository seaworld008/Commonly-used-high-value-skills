# v6.1.0 · 全量技能审查与来源修复

本版审查全部 293 个规范技能、16 个分类，修正 235 个入口，保留独有脚本、参考资料、系统契约、安全边界与验收规约。没有新增、退役或合并公开入口，永久退役名称不会回流。

## 主要变化

- 修正过宽触发、旧模型假设、不存在命令、错误引用、未经验证能力及多余审批流程。
- 修复缺数据时生成结论、认证接收方、未完成模型响应、批处理完整性、只读检查与原子文件交付问题。
- 新独立复查修复解包回滚丢失备份、普通 DOCX 原稿误拒绝、XLSX 完整校验旁路和稀疏工作表无界遍历。
- 补齐 Word、PowerPoint、Excel 和 Figma 实现指南的可执行案例与验收标准，保留原有质量门槛及完整创作工作流。

## 来源与许可

36 项错误 `in_house` 归类恢复为真实官方来源；两个 Figma 入口及配套资源、旧来源不可继续采用的实现从空白原创重建。Office 基于已核实的当前 Apache-2.0 材料重建，不能用新许可推断历史未知版本已有授权。

54 个字体配有 29 份家庭 OFL 通知；六个字体改用固定发行人原始版本。Web 归档保留 45 个组件及支持源码，并传播完整源通知及 101 个默认运行依赖的通知。缺少完整发行人证据的滚动条实现由原创本地 MIT 模块承担实际消费者接口，不伪造上游授权。

监控来源按固定提交审阅并保留本地策展；Hermes 稳定镜像更新至官方 `v0.23.2`。GSD Core/Pi 继续使用已审不可变安装器，不自动升级用户运行态。

## 使用与兼容

```bash
npx github:seaworld008/Commonly-used-high-value-skills#v6.1.0 install --target codex --dry-run
```

确认干运行结果后，按实际安装任务授权移除 `--dry-run`。本轮仓库维护没有改写用户全局技能或配置。

Office 无效结构、未确认公式缓存、不完整模型响应和失败交付会明确返回错误或未验收状态。调用方应读取退出码与结构化结果。

Web 模板使用固定锁文件，在已有兼容 Node/pnpm 环境内安装项目依赖，禁用依赖生命周期脚本；构建失败保留旧 HTML 与 dist。新增本地运行模块与发行人通知随技能完整分发。

## 验证范围

完整仓库流水线、来源、许可、安装器、打包、生成幂等性与精确 PR/main 检查构成发布门禁。实际合成验收包括稳定 LibreOffice 的计算回执、DOCX/PDF 渲染、Office 往返打包、默认沙箱 Chrome 与 FFmpeg 视频，以及干净 Web 模板的完整构建、离线交互和许可字节核对。

这些检查不等同 293 个外部账户、模型、桌面应用或生产环境均已实测。宿主 LibreOffice Alpha 缺少有效回执时仍报告未验收。
