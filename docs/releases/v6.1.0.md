**草稿，尚未发布。** 本地来源／许可门禁仍有阻断，必须先闭合[逐文件来源问题](../maintenance-provenance-2026-11-17.md)，再完成精确提交的验证、审阅、合并和制品核验。

本次维护逐项审查 **293 个规范技能 / 16 个分类**。保留有价值的脚本、参考、护栏与多技能工作流，没有新增或退役公开入口。

修正虚构命令、错误路径、未经请求的安装与持久化、固定宿主假设，以及文档与实际脚本输出不一致的问题。按固定提交选择吸收上游方法、安全和兼容性改动，保留本地策展。Hermes 稳定镜像升级到 v0.23.2。

执行辅助器的修正覆盖无证据合规状态、缺失财务数据、图谱媒体读取回执、扫描与测试失败门禁、生成代码的字符串边界，以及凭据、浏览器和Office辅助器的默认权限范围。渗透测试清单采用带年份的 OWASP 2025 分类，历史报告继续按原分类呈现。

独立复查后进一步修复认证接收方、失败状态、重复回执、旧文件交付和导出资源链接。许可审计同时检查独立安装包中的正文；`rust-engineer` 与 `security-review` 的旧实现因许可证据问题原创重建，Guizang 保留可核实的历史 MIT 快照与七份资产，未采用当前 AGPL 内容。

npm 制品同时包含发布历史和发行说明。具体来源观察提交、采纳与拒绝理由、验证结果和限制见[维护报告](../maintenance-audit-2026-11-17.md)。离线测试与静态检查不等于外部账户、真实模型、GUI或生产运行验收；本次未更改用户全局技能安装和配置。
