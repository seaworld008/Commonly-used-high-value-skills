# v4.1.0 — 上游契约策展与跨平台修复

本版更新 35 个公开技能及 AKS 嵌套 readiness，保留 **294 个技能 / 16 个分类** 和全部公开技能入口。

## 更新

- 工程方法：修复 React 重试与错误边界示例、空白字符串校验、性能清单代码围栏，以及调试示例的秘密泄露；文档审阅保留事实、决策条件和不确定性。
- 飞书：补齐任务分组的归属、分页和参考资源；更新 Base 提及示例、文档 URL 路由，以及支持气泡/瀑布/帕累托和 OOXML 属性的 Slides schema。
- AKS：移除虚构的 readiness assessment API，使用实际工具元数据读取和本地规则评估；新增带隐私投影回归的 jq 资源，区分默认与条件性策略，明确新目标集群迁移。
- Neon：修复 BM25 非匹配过滤与混合检索候选上限，补齐 embedding 维度和编码参考。
- HTML：修复 macOS `/tmp` 与 `/private/tmp` 别名下的受管报告更新，仍拒绝最终文件符号链接。

## Live Panel 许可范围与示例调整

保留固定来源的 MIT 渲染代码、全部许可原文和来源记录。原许可证对第三方示例设计/文案有明确保留，GitHub 将该组合文本分类为 `NOASSERTION`；本版没有放宽自动识别器。

发行包不再包含 `examples/codex-agents/`、`examples/airbnb/`、`examples/agent-architecture/` 三份非原创配置。使用新原创的 `examples/service-pipeline/config.json` 或自有配置；新示例的计数明确标为模拟数据。旧文件仍可从历史 tag/提交恢复，但不因此获得新的再分发授权。渲染器、帧检查、schema 与动画方法资源保留，快照的未来更新需人工复核。
