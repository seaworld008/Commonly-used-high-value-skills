# v4.2.0 — 旧版 PHP 运行时迁移技能

本版新增 1 个自研技能，共 **295 个技能 / 16 个分类**；已有技能的名称、路径和安装器 CLI 都不变。

## 新增

- `devops-sre/legacy-php-runtime-migration`：在不改代码、nginx 配置、定时任务和目录的前提下，把宿主机上停止维护的 PHP 换成带补丁的版本或同路径容器。适用于 CentOS 7、Remi、OneinStack 或手工编译的 PHP。
  - 入口：
    - 触发条件、核心原则、方案选择（含 compose 骨架和 `/usr/bin/php` 转发脚本）。
    - 8 步流程与每步的验收标准。
    - 回滚、日常维护、3 个示例、边界。
  - 引用：
    - 32 条踩坑记录。
    - 验证方法：按真实 SAPI 导出实际生效配置、新旧 FPM 并行对比、定时任务退出码、业务指标。
    - nginx 平滑升级。
    - 生产操作安全，例如：脱离 SSH 执行、只读诊断、"一直失败的任务不一定要修"、cron 邮件、发布兼容性。
  - 来源：方法来自两台测试主机、两台生产主机的实际迁移。内容是原创的，并已脱敏，不含主机、地址、业务名称或金额。参考实现见 [seaworld008/php-fpm-nginx-images v20261023.1](https://github.com/seaworld008/php-fpm-nginx-images/releases/tag/v20261023.1)。
