# v4.3.0 — 精选技能策展与验证流程升级

以 2026-10-24 的公开上游提交为审阅基准，对 **4 个现有技能** 更新。维持 **294 个规范技能 / 16 个分类**；没有增加、删除、改名或淘汰公开技能。

## 精选更新

- **Brainstorming**：保留长期任务的用户目标、已确认事实、决策取舍与验收标准；恢复上下文后不重复要求既有授权。
- **Writing Skills**：行为规则变化按场景评测，纯文字微调按确定性检查，明确不可把静态检查冒充模型评测。
- **Neon Postgres**：新增可选 Jev 重排序的适用条件、费用、模型可用性、租户权限过滤、RRF 回退与相关性评估。
- **Azure Kubernetes**：不再假设固定 MCP 工具名已安装；发现当前宿主真实支持的 AKS 工具与 schema。

## 来源与兼容性

Addy Osmani 和 Lark CLI 上游提交与上次审阅结果相同；Superpowers、Azure、Neon 有新提交，本版只策展其中已审阅且适用的变更。Simota 等未完成逐文件审阅的变更继续排队，**不声称全部来源都已升级至最新**。不改变 294 个公开路径和现有安装器入口。

## 验证及发布门禁

`python scripts/validate_repository.py --refresh`、`npm test`、来源/provenance、CodeQL、PR 与合并后 main 的精确提交验证、main Code Scanning 零开放告警、Release 制品独立下载与 SHA256 验证均为发布要求。仓库测试不等同真实 Neon/Azure 生产集成验收或模型行为评测。

[查看完整审阅及未关闭事项](../maintenance-audit-2026-10-24.md)。

## 版本连续性

历史 `v4.2.0` Release 于 2026-10-23 发布，指向随后从 main 回滚的 `30cf0bef` 提交。本版**不覆盖或改写历史标签**；使用全新 `v4.3.0` 标签，基于已恢复的 `v4.1.0` 基线和本次策展合并提交构建。因此本版变更范围标注为 `v4.1.0..v4.3.0`，而不是假装延续此前已回滚的代码路径。
