# v6.0.0 — 技能组合精简与真实契约修正

本 major release 基于 2026-11-04 的维护分支，退役三个职责重复的公开入口，修正一批早期 in-house 技能中的虚构接口、自主安装和未经请求的持久化，为 46 个技能补齐带触发条件的描述，并完成全量上游同步检查。规范仓库包含 **293 个技能 / 16 个分类**。

## 破坏性变更

- `skill-vetter` 已删除，改用 `skill-security-auditor`。人工审查方法（来源固定、权限与数据流地图、依赖审查、采纳记录）迁入其 `references/manual-review.md`。
- `github` 已删除，改用 `github-ops`。`gh` 认证复用、限流、告警分类、拆分 PR 与 CI 日志获取已并入。
- `neon-postgres-egress-optimizer` 已删除，改用 `neon-postgres`。上游已退役该技能并把数据出口优化并入 `neon-postgres` 的 `references/egress-optimization.md`。

## 主要优化

- 46 个技能（29 个 simota 智能体、Notion、Linear、安全扫描器、Sentry 等）的描述从名词罗列改为明确的“何时使用”触发条件，并修复多处被截断的中文描述；组合审计平均分由 92.1 提升到 94.2。
- `neon-postgres`：三方合并上游最新版本，新增数据出口优化与分支工作流参考，保留本地的授权边界与不自动安装策略。
- `hermes-agent`：随上游升级到 v0.22.7，包含更可靠的 tmux 派生会话、无 tmux 时的 PTY 回退和新的项目工作区参考。
- `find-skills`：按“宿主技能 → 本仓库目录 → 公开目录”检索并按证据比较；只在用户请求时安装，安装前先做安全审查。
- `link-checker`：新增只读脚本 `scripts/check_links.py`，提供逐跳状态、HEAD→GET 回退、按主机限速、风险提示和 CI 友好的退出码；不再伪装浏览器。
- `figma`：使用 Figma MCP 的实际工具名，补充 node-id 解析、截断处理和排查表。
- `github-ops`：删除组织专用的 `NOJIRA` 标题约定，改为遵循目标仓库自己的规范。
- 10 个金融技能与 `frontend-design`：不再默认写入 `MEMORY.md` 或设置定时任务。

## 上游同步

全量检查 163 个上游来源：`hermes-agent` 已升级；`llm-wiki` 跟随上游路径迁移；`systematic-debugging` 移除上游已删除的测试附件；`honcho` 因上游删除而转为固定版本的本地归档快照；复查后 46 个来源与上游一致、无不可用来源，检查过期的 4 个来源已记录检查日期。89 个 default-branch 来源仍需人工复核，检查点保持不变。

## 验证边界

完整仓库流水线、Python 测试、来源/许可证/资源与生成物幂等性检查通过。静态门禁不代表真实 Figma、GitHub 写操作、Neon 或 Hermes 运行时以及模型行为验收。

详细记录见 [维护报告](../maintenance-audit-2026-11-04.md)。
