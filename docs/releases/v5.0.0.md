# v5.0.0 — 全量策展、能力扩展与可信发布

本 major release 基于 2026-10-26 合并后的 `main`，将全量来源策展、技能审计边界修复和三个明确能力缺口纳入正式发布。规范仓库包含 **296 个技能 / 16 个分类**。

## 主要变化

- 完成来源审阅与 provenance v2 整理，补齐许可证全文、引用资源和来源资产检查；固定提交审阅保留本地策展，不把监控源误报为持续最新。
- 将 `self-improving-agent` 的可复用控制改进方法迁入 `reflect-learn` 的 `controlled-improvement` 参考资料，并删除旧公开入口。需要该方法的用户应改用 `reflect-learn`。
- 新增 `shadcn`，用于组件、注册源、主题和交互验收；新增 `security-model`，用于安全模型策略解析、可信 base 和陈旧引用检查；新增原创 `remotion-video`，用于 Remotion 时间线和媒体元数据验收。
- 修复技能扫描器、Graphify chunk receipt/cache 顺序、LinkedIn/Xquik 授权边界，以及安全策略解析器的固定提交路径和空白目录处理。

## 来源与许可

外部资产保留不可变提交、许可证、版权和 attribution。Remotion 上游技能缺少可接受的宽松许可证，因此本仓库只提供原创实现和官方 API 事实参考，不复制其技能文本或脚本。

## 兼容性

`self-improving-agent` 是公开入口删除，属于破坏性变更；旧调用方应迁移到 `reflect-learn`。其他既有技能路径和安装器目标保持可用。

## 验证边界

本版经过完整仓库流水线、820 项 Python 测试、65 项 Node 测试、来源/许可证/资源/安装器/打包/CodeQL 和 GitHub Release 制品校验。静态门禁不代表真实浏览器、视频播放、云服务、账号操作或模型行为验收。

详细审阅记录见 [维护报告](../maintenance-followup-2026-10-26.md) 和 [新增技能评估](../maintenance-additions-2026-10-26.md)。
