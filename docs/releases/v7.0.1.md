# v7.0.1 · 租户隔离补丁、审查修复与浏览器基础能力升级

本补丁版本（Patch Release）针对 `v7.0.0` 发布后 [PR #164 审查](https://github.com/seaworld008/Commonly-used-high-value-skills/pull/164#discussion_r4662432039) 指出的模板缺项进行紧急补全，并同步关闭其余 3 项审查意见、加固跨平台换行配置、升级浏览器基础能力与活跃上游检查点；全仓维持 **295 个规范技能 / 16 个分类**，向后兼容 `v7.0.0`。

## 重点修复：`database-designer` 多租户 PostgreSQL RLS 补丁

- **补全父子表 RLS 与组织成员校验**：在 [`skills/developer-engineering/database-designer/references/orm-and-rls-patterns.md`](../../skills/developer-engineering/database-designer/references/orm-and-rls-patterns.md) 与对应 `openclaw-skills/database-designer/` 镜像及 [`SKILL.md`](../../skills/developer-engineering/database-designer/SKILL.md) 中，补回 `organizations` / `users` / `organization_members` / `projects` / `tasks` 完整建表 DDL、无 `BYPASSRLS` 的非表所有者角色 `app_user` 最小权限授权（排除 `project_id`、`created_by_id`、`deleted_at` 的直接 `UPDATE`，禁止修改 `organization_members`），并在 `organization_members`、`projects`、`tasks` 三张表同时开启 RLS 与成员/角色校验策略（`org_members_self_read`、`projects_member_read`、`tasks_read`、`tasks_insert`、`tasks_update`、`tasks_delete`）。
- **受控软删除 RPC**：针对 PostgreSQL 在带 `WHERE` 的 `UPDATE` 上同步对新行校验 `FOR SELECT` 策略（`deleted_at IS NULL`）的特性，提供固定 `SET search_path = pg_catalog, public` 的 `soft_delete_task(p_task_id TEXT)` `SECURITY DEFINER` 函数并仅向 `app_user` 授权执行，同时更新 `database-designer/README.md` 目录树与路径。
- **真实 PostgreSQL 租户隔离回归测试**：新增 [`tests/test_database_designer_rls.py`](../../tests/test_database_designer_rls.py)，直接提取文档 SQL 块由非超级用户 `schema_owner` 建表建策略，并切换至非所有者应用角色 `app_user` 实测双租户正常读写、软删除、跨租户读写删拦截、伪造 `created_by_id`、列权限篡改、只读 `viewer` 拦截、创建者与管理员删除分层及未设会话用户 fail-closed 行为。
