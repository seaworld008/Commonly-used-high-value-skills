# v4.0.0 — CodeQL 安全修复正式版

2026 年 10 月 12 日检查发现 v3.3.0 在 Code Scanning 中有 **18 条开放告警（14 High、4 Medium）**，集中在新引入的 HTML CLI（17 条）与 Live Panel 模板（1 条）。此版以实际防护代码修复风险，而不是隐藏源文件或忽略告警。

## 安全更新

- 用离线受限 Markdown→HTML 执行器替换包含注入、ReDoS、文件竞争及不完整转义问题的约 800 KB 上游打包 CLI；提供静态多面板、表格、代码和简单 flow。
- 提供默认 CSP、特殊字符统一转义、输入/报告大小限制、随机安全文件名、O_EXCL/O_NOFOLLOW 和精确受管路径校验。
- Live Panel 仅接受 Python 本地渲染器嵌入的 JSON，禁用 URL 参数 fetch，并通过 connect-src 'none' 限制浏览器出网。
- 引入高优先级安全回归测试，GitHub Verified Release 发布链路在校验 main SHA 和 CodeQL 成功之后，还会检查 main 的开放 Code Scanning 告警必须归零。

## 重要兼容性变化

为避免把原始危险能力暴露给 Agent，HTML CLI 不再提供 serve、clean、update、自动打开浏览器、远端语音、任意本地文件/图片嵌入与 raw HTML/SVG 代码执行。需要完全兼容原第三方 CLI 的用户应保留旧部署，并自行承担安全审计和隔离责任。

由于这些行为属于原 CLI 的功能接口变化，本次提高主版本到 v4.0.0。原有 **294 个 Skills / 16 分类保持不变**。

## 验证

正式发布须通过仓库全量测试、许可证及受管来源一致性、Ubuntu/Windows 安装器矩阵、CodeQL 和实际 main 告警零开放门禁。只有完成四份 Release 资产下载、SHA-256、版本及技能清单校验后才公开。
