## 门禁与独立复查

每个外部 origin 必须有自己的同提交许可检查点、匹配的 Git blob、SHA256 和完整正文。`in_house` 不豁免明确再分发禁令。OFL 仅允许具体字体及通知文件，并在同步器中限于不可变归档 sidecar；不能成为代码许可或第二同步 authority。

许可证识别保留完整文本校验，仅补入已核实的完整 Apache 无附录变体与 OFL 的 HTTPS 链接形式。改写许可条款、追加禁令、混入代码、伪造字体或更换检查点的负例继续失败。

新独立复查复现的四项问题均已修复：解包发布和回滚同时失败时保留可恢复备份；普通无修订 DOCX 可带原稿验证打包；XLSX 打包使用完整 XSD/唯一 ID 校验；稀疏工作簿按实际存储坐标读取并限制资源。相应回归使用真实 OOXML 组合及故障注入。
