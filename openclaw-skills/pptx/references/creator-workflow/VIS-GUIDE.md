# 逐页视觉检查

检查应使用最终导出的页面，而不只看制作代码。自动边界检查能发现对象越界，
但发现不了错误换行、字体替代、图例压住数据或图片被裁掉的含义。

## 三种观看尺度
1. 缩略图总览：检查标题、页脚、色彩角色和信息密度的连续性。
2. 单页实际大小：检查正文、来源、图例与数据标签能否读清。
3. 放大局部：检查曲线、字符、表格边缘和遮挡；放大可读不等于投影可读。

## 文本与对齐
检查最长标题、最多文字的一页和中英文混排页。
逐项确认文本仍在框内、行末不截断、数字和单位没有被分开、列表缩进一致。
共享左边线的对象应视觉对齐；圆形或图标可作少量光学修正并保持一致。
若版面太挤，先缩短表达或拆页；修复后重新查看相邻页的节奏。

## 图表与数据
从图中抽取至少一个值与输入表复算，关键结论涉及的值全部复核。
确认单位、分母、样本规模、时间区间、排序、刻度与来源清楚。
条形长度应以零为基线；截断坐标的其他图应清楚标明范围。
检查图例顺序与绘制顺序一致，颜色和图案不会暗示不存在的分组。
图表自动渲染成功后仍须检查标签密度，脚本不保证任意长标签都能放下。

## 技术与可访问性
检查缺字、字体替代、透明图片边缘、链接、备注和阅读顺序。
有可编辑要求时，打开 PPTX 实际修改文本和图表数据，再检查重排是否合理。
SVG 中保留文字不等于 PowerPoint 原生图表；PNG 是位图。
对需要辅助阅读的内容补充准确替代文本，复杂图表在备注中说明主要结论与数据表位置。

## 记录与回归
以页面 ID 记录问题，附截图坐标或对象名、严重程度、修复动作与复查状态。
每页至少记录一次内容、视觉、技术三类检查，即使某类为“不适用”。
共用主题、字体或母版变化后，复查全部页面。
只有代码或 XML 检查时明确写“尚未视觉验收”，不能填写视觉通过。
评分与阻断判断使用[评分规则](RUBRIC.md)，交付文件使用[清单](CHECKLIST.md)。
