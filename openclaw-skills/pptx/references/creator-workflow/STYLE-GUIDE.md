# 可复用的页面视觉系统

从内容关系确定版式，再将其固化为主题参数。下列数值是本工作流的新建议，
不是所有场景的硬性门槛；最终以目标显示环境中的实际可读性为准。

## 页面与网格
宽屏任务可采用 16:9；沿用客户模板时保持模板原比例。
以 13.333 × 7.5 英寸页面为例，四周留 0.55 英寸安全边距，
标题区约 0.8 英寸，页脚约 0.35 英寸，内容区在二者之间。
两栏页面预留至少 0.3 英寸栏间距，按同一基线对齐栏标题。
这些参数应集中定义，避免散落在逐页代码里。

## 字体与文本
用一个正文字体家族，必要时为标题增加一个已许可字体。
中文、拉丁字符、数字与标点都必须测试；某字体存在不代表覆盖中文字符。
建议起点为标题 30–36 pt、正文 22–26 pt、来源 12–14 pt。
远距离投影需要更大字号；密集数据可进入附录，不能靠细小来源行隐藏限制。
行长以自然语义分组，避免将数字与单位拆到不同行。
相同级别采用一致的字重与行距；通过真正的段落结构形成层级。
目标环境缺字时换用实际安装且许可允许的字体，并重新渲染。

## 颜色角色
原创示例：深蓝灰 #203746 作主文本，米白 #F8F6F1 作背景，
青蓝 #245A73 表示主要数据，陶橙 #BE632B 表示待关注项。
这些是角色分配示例，不应取代既有品牌约束。
普通正文对比度以至少 4.5:1 为设计目标，大字至少 3:1。
为趋势增加线型或标记，为状态增加文字；不能只靠红绿区分含义。
同一组别跨页保持颜色一致；强调色只用于需要关注的结论。

## 版式选择
| 内容关系 | 建议版式 | 容易出现的问题 |
| --- | --- | --- |
| 单一关键发现 | 结论标题＋一张主图＋限定说明 | 多个装饰图抢占图表空间 |
| 两方案比较 | 同结构双栏，共用评价维度 | 两栏指标口径不同 |
| 流程或依赖 | 有方向的步骤图，注明条件分支 | 箭头暗示未证实的因果 |
| 密集证据 | 附录表格与来源索引 | 表格截图导致无法编辑 |

在[视觉检查](VIS-GUIDE.md)中用实际页面检验这些选择。
