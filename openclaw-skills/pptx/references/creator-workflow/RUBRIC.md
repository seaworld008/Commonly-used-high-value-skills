# PPT 质量评分与阻断缺陷

采用十项各 0–10 分、总分 100 分的方法。
先做初评；总分低于 75 时，确定前三项弱点，修复后重新评分。
分数评价质量，阻断缺陷决定能否交付，两者分别记录。

## 十项评分
| 项目 | 检查对象 | 高分需要的证据 |
| --- | --- | --- |
| 目标清晰度 / Goal Clarity | brief、开场、结束页 | 受众、问题与最终行动一致 |
| 叙事结构 / Story Structure | 大纲和页面顺序 | 每一步为下一步提供必要前提 |
| 页面断言 / Slide Assertions | 各页标题 | 标题明确且得到本页内容支持 |
| 证据质量 / Evidence Quality | 来源与计算台账 | 关键数字可复算，假设有标记 |
| 图表适配 / Chart Fit | 问题与图表类型 | 比较关系准确，单位及轴不误导 |
| 视觉与可访问性 / Visual & Accessibility | 全部页面预览 | 可读、无溢出、对比清楚、不只依赖颜色 |
| 连贯与过渡 / Coherence & Transitions | 跨页定义及讲稿 | 术语、单位一致，过渡解释关系 |
| 可讲述性 / Speakability | 试讲或朗读记录 | 在可用时间内说清结论与限制 |
| 交付完整性 / Deliverables Complete | 文件清单 | 约定格式、来源、讲稿和源材料齐备 |
| 稳健性 / Robustness | 重建与应用检查 | 文件打开有效，可编辑要求得到验证 |

每项以 0 表示无有效产物，1–4 表示缺少主要依据，5–7 表示核心内容成立但存在明显缺口，
8–9 表示证据充分且仅余局部改进，10 表示该项要求均有验证记录。
这些分档说明是本版本为统一评分新增的操作解释。
未检查的事项注明“未验证”，按已有证据保守评分，不能把预计结果计作实测通过。

## 逐页审阅记录
每页分别记录：
- 内容：标题、数字、单位、来源和限定条件。
- 视觉：可读性、对齐、留白、溢出、图表标签与页面一致性。
- 技术：对象可编辑性、媒体引用、字体、备注及渲染状态。
逐页缺陷汇总到整套十项评分；不要用全套平均分掩盖某页的错误数据。

## 必须阻断的缺陷
关键结论与数据相反，数据伪造或把缺失值当零，来源无法追溯且影响决策，
关键文字被遮挡或无法阅读，文件无法打开，要求可编辑的对象仅剩截图，
以及约定的核心交付文件缺失，均须修复或明确降级为未完成草稿。
总分超过门槛也不能覆盖这些缺陷。

## 修复与复评
从影响决策的错误开始，再解决可读性和技术问题，最后处理局部美化。
总分低于 75 时写出前三项弱点、对应页面、具体动作和预期验证方式。
修复后重新核算受影响项目并保留前后评分，检查是否引入新的跨页不一致。
重复修复不应无限循环：按任务时间安排迭代；时间耗尽仍不达标时交付草稿状态与缺口，
不得为赶时间上调分数。每轮记录剩余时间、仍未解决的问题与下一步验证动作。
正式完成需要总分至少 75、阻断缺陷为零，且约定检查完成；否则准确标记待验收。

## 合成评分示例
某培训试点汇报十项初评为 8、7、7、6、7、7、8、7、8、7，总分 72。
前三项改进选择证据质量、页面断言和图表适配；同分时优先影响决策的项。
核对分母并改写相应标题后，按实测结果重新评分，而非自动给每项加分。
此例只演示记分方法，不代表任何真实报告已通过验收。
