# Source-Grounded Mind Map Review

Use a mind map to expose topics and relationships in the selected notebook
sources. A diagram is a navigation and explanation aid, not independent evidence.
This local worksheet preserves useful design guidance without inventing a
missing upstream reference file or a programmatic Mind Map API.

## Prepare

- Confirm the selected sources, intended audience and question to explain.
- Group overlapping concepts before choosing a few legible top-level branches.
- Keep one term per concept; record essential synonyms in the source glossary.
- Separate source-supported relationships from interpretations or open questions.

## Inspect the Actual Output

1. Generate using the product feature actually available to the account.
2. Expand representative branches and check that labels remain readable.
3. Select a node and inspect its supporting source context through the available
   chat/navigation controls. Revisit the original source for important claims.
4. Check that broad branches do not hide conflicting sources or missing evidence.
5. If it is too dense, narrow the source set or scope; a branch count is a design
   preference rather than a guaranteed prompt-controlled product parameter.

## Handoff

For a slide or infographic, preserve the checked topic hierarchy and source
references instead of treating a screenshot as editable structured data.
Sharing a notebook and sharing a downloaded image have different access scopes;
use only the sharing destination the user requested. Availability, download rights
and usage limits depend on the actual product/account and source restrictions.

Acceptance: legible hierarchy, consistent labels, traceable sampled claims, no
unsupported relationship presented as a source fact, and an authorized export.
