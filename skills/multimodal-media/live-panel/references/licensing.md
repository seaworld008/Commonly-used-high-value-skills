# Bundled licensing boundary

The engine, Python helpers, and method references come from
`ythx-101/live-panel-skill` at immutable commit
`2a5dc1ea9983c193f20c9ff4000c8a11efb3b5e1`.
Keep the complete upstream `LICENSE.txt`, including its attribution note.

That license expressly covers repository code under MIT while reserving the
original authors' rights in recreated example designs and wording. GitHub
classifies the combined file as `NOASSERTION`; the repository's automatic
canonical-template detector therefore cannot certify it. Its failure remains
recorded; no global SPDX detection rule or fingerprint was relaxed.

The previously bundled Codex, Airbnb, and agent-architecture example configs
are excluded from the current installable tree. Their topology, text, layout,
and figures are not reused in the replacement example. Existing Git history
retains the old files and notices for recovery, not as newly licensed assets.

`examples/service-pipeline/config.json` is an original MIT-licensed example
authored for this collection. Every counter is simulated and the credit line
states that fact. It demonstrates the existing renderer's documented schema
without recreating a third-party image or presenting public figures as data.

The local hardened implementation is governed as a fixed, manually maintained
snapshot. The external origin retains its upstream identity and MIT lineage;
the original example and this reference are tracked under `local-repo/curation`.
Future updates require a new content and licensing review.
