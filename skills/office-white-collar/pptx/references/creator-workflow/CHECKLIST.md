# 最终验收与交付清单

每项记录通过、失败、不适用或未执行；通过必须有对应文件、计算或实际观察。
未执行的视觉检查必须列入交付限制。

## 内容与证据
- [ ] 开头明确受众需要解决的问题，结尾给出行动或选择条件。
- [ ] 每页标题与图表/正文支持同一断言，术语和数值前后一致。
- [ ] 所有关键数据有来源定位、时间、单位、分母和计算说明。
- [ ] 合成演示数据明确标识；假设与待核实事实没有伪装成实测结果。
- [ ] 图片、字体、外部资料的来源、许可和必要署名可追溯。

## 逐页视觉
- [ ] 已检查全部页面，标题、正文、图例、来源均可读。
- [ ] 无遮挡、溢出、意外裁剪、缺字；对齐与边距一致。
- [ ] 图表有合适坐标、真实数据、清晰单位；图例和标签完整。
- [ ] 颜色角色、字体层级、页码与页脚在整套页面保持一致。
- [ ] 已记录所用渲染器以及目标环境中尚未检查的差异。

## 技术与编辑
- [ ] PPTX 文件可解包且引用关系有效；结构检查不代替应用打开检查。
- [ ] 目标应用打开无修复提示，页数与大纲一致。
- [ ] 要求编辑的文本、形状、表格和图表经实际修改验证。
- [ ] 静态 SVG/PNG 与原生图表在资产清单中明确区分。
- [ ] 外链、备注、替代文本和必要的内嵌数据符合任务要求。
- [ ] 源代码、数据和依赖版本足以复建，未执行复建则如实注明。

## 导出包
按已约定格式交付最终 PPTX、PDF、逐页预览、讲稿、来源台账和重建材料；
未要求的格式可标为不适用，不能声称已生成。
清单列出每个文件的路径、用途、版本或哈希、页数和验证状态。
预览、PDF 和 PPTX 必须来自同一最终版本；删除过时引用而不是混入旧预览。
如某格式导出失败，保留完整有效的其他文件，明确指出失败项和实际错误。

## 发布判定
使用[RUBRIC](RUBRIC.md)记录十项评分、总分、前三项弱点和修复记录。
总分达到 75 仍需清除全部阻断缺陷；未完成目标应用检查时标记待验收。
交付说明先写已完成内容，再列限制、复核入口与建议的后续检查。
