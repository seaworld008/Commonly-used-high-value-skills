# 方法分工与交接约定

这里的角色代表职责。同一个执行者可以依次承担全部职责；
仅在宿主支持且任务允许时才由多位执行者协作，无须递归启动角色。

| 职责 | 接收 | 产出 | 交接前要回答的问题 |
| --- | --- | --- | --- |
| 内容策划 | brief、受众疑问 | 逐页断言、大纲、讲述顺序 | 最终行动是否回应最初问题？ |
| 证据核对 | 原始数据、来源台账 | 清洗记录、计算结果、证据 ID | 比较对象和单位能否一致复算？ |
| 视觉设计 | 页面卡片、主题约束 | 网格、图示方案、样页 | 不靠颜色能否理解图意？ |
| 制作 | 已核实内容、图表、主题 | PPTX、源文件、讲稿 | 需要编辑的对象是否仍为原生对象？ |
| 验收 | 渲染结果、交付要求 | 逐页问题、评分、验收记录 | 是否存在必须阻断交付的缺陷？ |

## 一个贯穿全程的页面 ID
用 S01、S02 等稳定 ID 关联大纲、证据、代码、讲稿和缺陷。
改动顺序时保留 ID，在导出时记录当前页码；不要让“第 7 页”成为唯一定位方式。
每张页面卡记录标题断言、证据 ID、对象类型和验收重点。
数据重算时先更新证据及图表，再更新页面结论，最后更新讲稿。
主题调整应重新审阅全部页面，因为它可能改变换行与对象位置。

## 交接示例（合成场景）
策划提出 S03：“本季度试点需求主要来自培训团队”。
证据核对发现三组样本量不同，交回分母与绝对人数，避免只展示百分比。
设计选择带人数标签的横向条形图，并在页脚说明合成数据。
制作保留标题、注释和图例的原生文本，图表对象类型另行登记。
验收在渲染图中检查末尾标签，在源文件中复算分组人数。

## 变更影响
- 结论变更：回查相关证据、标题和行动建议。
- 数据变更：重算图表、数据标签、摘要数字和讲稿。
- 字体变更：重查所有文本框的换行、行距与溢出。
- 文件名或输出目录变更：重查交付清单和源文件引用。
- 渲染器变更：重新记录视觉检查结果，不沿用旧截图的通过结论。
